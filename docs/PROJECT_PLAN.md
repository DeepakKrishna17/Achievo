Achievo
Track. Reflect. Improve.

## Vision:
Achievo helps people build better habits and achieve their goals by tracking daily activities, encouraging self-reflection, and providing meaningful progress insights.

## Target Users
- Students
- Teenagers
- Working Professionals

## Problem Statement
Many people set goals but fail to stay consistent. Existing task trackers often focus only on completing tasks instead of helping users understand and improve their habits.

## Solution
Achievo allows users to:
- Create goals
- Track habits
- Reflect daily
- Review weekly/monthly progress
- Build consistency through analytics

## MVP Features
- User Authentication
- Dashboard
- Goals
- Habits
- Daily Reflection
- Analytics

## Future Features
- AI Insights
- Calendar
- Mood Tracking
- Notifications
